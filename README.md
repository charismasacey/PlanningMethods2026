# CP201A: Planning Methods Gateway
## UC Berkeley, Fall 2026

This repository holds the Python notebooks and data files for CP201A, the Master of City Planning first year methods course, taught by Professor Charisma Acey with GSIs Madison Dugar and Brittany Vang.

**Students: you don't need anything from this page.** Use the lab links posted on bCourses; they open each notebook directly in Berkeley Datahub in your browser, with nothing to install.

If you are running Python on your own computer instead of Datahub, download the current week's files from the matching folder here (for example, Week01_Lab_IntroPython). Download every file in the
folder, not just the notebook, and keep them together in one folder on your computer. See the Installing Python guide on bCourses for setup.

**A note about GitHub's preview:** when you click a notebook file on this site, GitHub sometimes shows a pink "Unable to render code block" message instead of a preview. This could be an extension interfering with Github's preview (esp. in Chromium browsers) or is a glitch in GitHub's preview feature, not a problem with the notebook. The file itself is fine, it will open normally in Datahub and in Jupyter, and no action is needed from you. If you want to preview a notebook in your browser before downloading and it's not rendering here, copy the notebook's web address, go to https://nbviewer.org, and paste the address into the box there.


These course materials build on notebooks originally developed by Professor Carolina Reid.
