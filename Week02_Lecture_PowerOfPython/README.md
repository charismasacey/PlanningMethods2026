# Week 2 Lecture: The Power of Python

In-class demo for the Wednesday 9/2 lecture (Python Fundamentals: Working with Data in Python). We run it together to see what Python can do with real planning data before we learn the pieces: it maps Oakland's 1930s redlining grades and compares them to neighborhood conditions today. Open it through the Datahub link on bCourses to follow along. Files in this folder (own-laptop users: download all of them, and keep the four shapefile pieces together):

- Lecture_PowerOfPython_9-2.ipynb (the notebook we run in class)
- CAOakland1937.geojson (the 1937 HOLC "redlining" map for Oakland)
- Oakland_1990_2017_Data.xlsx (census and ACS data the notebook reads)
- Oakland_Tracts.shp, Oakland_Tracts.dbf, Oakland_Tracts.shx, Oakland_Tracts.cpg (census tract boundaries that the notebook maps; these four go together)
